# Axiom (Barry bag)

Query and search [Axiom](https://axiom.co/) log datasets using APL.

## Tools

- `search` — search logs by text, service, level, and time range
- `query` — run a raw APL query against log datasets
- `tail` — live-tail logs with optional filters
- `aggregate` — run aggregation queries (count, avg, percentiles, etc.)
- `context` — get surrounding log lines for a specific log entry
- `services` — list available services in the log dataset
- `datasets` — list available Axiom datasets
- `network_search` — search network/request logs
- `network_stats` — get network traffic statistics
- `status` — check Axiom connection status
